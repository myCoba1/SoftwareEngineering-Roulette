# SoftwareEngineering‑Roulette

## Overview

SoftwareEngineering‑Roulette is a fully functional *roulette simulation engine* written in **Scala**. Its purpose is to model a roulette game, handle bets, determine outcomes, and provide a basis for further extensions

Key goals of this project:
- Demonstrate core software engineering principles (modular design, testing, build automation)
- Provide an extendable simulation model for the roulette game
- Serve as a portfolio example of a Scala + SBT project


## Technologies

- **Scala** — primary programming language  
- **SBT** — build tool for compilation, testing, and dependency management  
- Testing framework
